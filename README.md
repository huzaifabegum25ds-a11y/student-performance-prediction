# 🎓 Student Performance Prediction

## About the Project

Student Performance Prediction is a Machine Learning project that predicts
a student's final score based on study hours, attendance percentage,
and previous score.

## Objective

The objective of this project is to understand the complete Machine
Learning workflow and apply it to a simple real-world problem.

## Features

- Takes student-related information
- Trains a Machine Learning model
- Predicts final student scores
- Evaluates the model
- Displays prediction results

## Technologies Used

- Python
- NumPy
- Scikit-learn
- Linear Regression

## Machine Learning Workflow

1. Collect data
2. Prepare the dataset
3. Split data into training and testing sets
4. Create the Machine Learning model
5. Train the model
6. Test the model
7. Evaluate the model
8. Make predictions

## Input Features

- Study Hours
- Attendance Percentage
- Previous Score

## Output

The model predicts the student's expected final score.

## Example

Study Hours: 7

Attendance: 85%

Previous Score: 80

The model predicts an expected final score.

## Learning Outcome

Through this project, I learned how to build a complete Machine Learning
project using Python and Scikit-learn. I learned about data preparation,
model training, testing, evaluation, and prediction.
